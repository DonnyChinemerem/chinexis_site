CHINEXIS TECHNOLOGIES WEBSITE

Files required:
- index.html (rename chinexis_index.html to index.html before uploading)
- style.css

Keep both files in the same folder. The HTML links to style.css using a relative path.

GitHub Pages deployment:
1. Create/open your GitHub repository.
2. Upload index.html and style.css to the repository root (same level, not inside separate folders).
3. Commit the changes to your main branch.
4. Open Settings > Pages. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for the Pages deployment to finish and open the published URL.

The contact form uses a mailto link, so it opens the visitor's configured email app; it does not send/store messages on a server.
